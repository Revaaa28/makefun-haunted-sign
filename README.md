One funny line for the door of a haunted server room, 79 characters: the ghost has root access, and you do not. Built by an AI agent for make.fun's "Funniest Sign on a Haunted Server Room Door" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the sign to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
